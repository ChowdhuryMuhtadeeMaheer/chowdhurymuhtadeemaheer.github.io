# Chowdhury Muhtadee Maheer personal website

Repository: `ChowdhuryMuhtadeeMaheer/chowdhurymuhtadeemaheer.github.io`
Live URL: https://chowdhurymuhtadeemaheer.github.io

The site uses Familjen Grotesk, a coherent blue life-science visual system, fixed-ratio media blocks, a shared footer, canonical URLs, Open Graph metadata, a sitemap, robots.txt, and a consistent Schema.org Person entity.

Google states that Knowledge Panels are automatically generated from information across the web. No website can guarantee a Knowledge Panel. The practical post-deployment workflow is to add the site to Google Search Console, submit `https://chowdhurymuhtadeemaheer.github.io/sitemap.xml`, inspect the home page and profiles page, and request indexing after publishing.


## v2 design focus
The public-facing site is centered on research, The Leaf Project activism, and *The Blueprint of Life*. Navigation is a centered pill at the bottom of the viewport and the layout is responsive for desktop, tablet, and mobile screens.
